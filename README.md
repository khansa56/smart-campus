# Smart Campus Student Portal

**A Modern, Responsive, and User-Friendly Student Dashboard**

A front-end web application designed to provide students with a centralized platform for accessing academic information, managing coursework, reviewing schedules, and staying informed about campus activities.

## Project Overview

The **Smart Campus Student Portal** is a web-based academic dashboard developed to demonstrate the practical application of front-end web development technologies. The system brings essential student-related information together in one organized interface, helping students navigate academic activities efficiently.

The portal features a modern user interface, structured navigation, responsive layouts, and interactive components to create a smooth and accessible user experience.

## Key Features

- **Student Dashboard:** Provides an overview of academic progress and important student information.
- **Course Management:** Offers a dedicated section for viewing course-related information.
- **Academic Schedule:** Organizes classes and upcoming academic activities.
- **Task Management:** Provides a structured interface for reviewing assignments and academic tasks.
- **Student Profile:** Presents student-related profile information in a dedicated section.
- **Campus Announcements:** Displays academic updates, general notices, and campus events.
- **Interactive Navigation:** Enables convenient movement between different portal sections.
- **Dark Mode:** Includes a theme-switching interface for a more personalized browsing experience.
- **Responsive Design:** Designed to support a range of screen sizes and devices.

## Technologies Used

## Getting Started

Follow these steps to run the project locally:

1. Clone or download this repository.
2. Open the project folder on your computer.
3. Locate the `index.html` file.
4. Open `index.html` in a modern web browser.
5. Navigate through the portal to explore its available sections.

No additional development environment is required to view the basic front-end interface.

## Scope and Limitations

This project is a front-end prototype intended for educational and demonstration purposes. Features such as student authentication, persistent data storage, administrative controls, and integration with a university database would require additional backend development.
