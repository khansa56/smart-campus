SMART CAMPUS STUDENT PORTAL
Front-end prototype for Web Technology Lab Assignment 1

CONTENTS
- index.html: Home page, dashboard and announcements
- courses.html: Dynamic course cards with search and filters
- schedule.html: Weekly class timetable
- tasks.html: Add, complete and delete tasks with localStorage
- profile.html: Registration form with inline JavaScript validation
- css/style.css: Responsive design and light/dark theme styles
- js/main.js: Navigation, theme, dashboard, announcements and form validation
- js/courses.js: Course data, dynamic rendering, search and filters
- js/tasks.js: Task management and browser storage

HOW TO RUN
1. Extract the ZIP file to a folder on your computer.
2. Open the extracted folder.
3. Double-click index.html to open it in Chrome, Edge or another modern browser.
4. Use the navigation menu to visit all pages.
5. Add sample tasks and refresh the page to test localStorage.
6. Use the Dark mode button to test the saved theme preference.

NOTES
- This is a front-end prototype only. It has no back-end database or real university login.
- Sample instructors, schedule, course data and announcements are for demonstration. Replace them with accurate information as needed.
- Do not enter a real password in the demo registration form.
- Google Fonts require an internet connection; the page still works with fallback fonts offline.
